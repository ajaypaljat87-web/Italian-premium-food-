# Premium Italian Food

A bilingual English/Italian B2B enquiry website for professional buyers interested in Italian olive oil and wine.

## Website features

- Responsive layout for phones and computers
- English / Italian language switch
- Product enquiry sections for olive oil and wine
- Buyer information for importers, distributors, wholesalers, hotels, restaurants and specialist retailers
- WhatsApp enquiry form using the business contact number
- Direct business email and WhatsApp links

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Open **Pages** in the left menu.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. Open the **Actions** tab and check the workflow named **Deploy website to GitHub Pages**.
5. When the workflow finishes successfully, GitHub will show the public website URL in **Settings → Pages**.

A deployment workflow is included at `.github/workflows/deploy-pages.yml`. It runs automatically whenever changes are pushed to the `main` branch.

## Important before accepting orders

This website is an enquiry channel, not proof that products are currently available or that a sale/export is legally cleared. Confirm supplier authorisation, product origin, specifications, packaging, quantities, prices, food documentation, export/import permissions, tax obligations, shipping and destination-market rules before making any offer or accepting payment. Wine enquiries should be handled only with appropriately licensed trade buyers.

The enquiry form opens WhatsApp with the details prepared; it does not store submissions in a website database or send automatic email notifications.
