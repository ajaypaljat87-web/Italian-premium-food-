# Premium Italian Food

A static B2B website connecting Indian importers and distributors with Italian olive oil and wine suppliers.

## Contact

- Email: contact@ajayandcompany.com

## Enquiry form
The form opens WhatsApp with the enquiry prefilled. It does not store submissions or send email notifications.

## Before commercial launch
Replace generic stock photography with supplier-approved images and verify product availability, specifications, origin claims, certifications, export documentation, pricing, and shipping terms. Wine enquiries are restricted to licensed importers/distributors; confirm all applicable Italian and Indian import, labelling, tax and state licensing requirements.

## Hosting
Static site entry point: index.html. Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root) → Save.
